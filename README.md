# Roblox Username Checker

I made this tool to help find available Roblox usernames without having to keep checking them manually. It can generate usernames, check if they're available, save the good ones, and keep track of your stats over time.

It uses Roblox's public username validation API and has a modern terminal interface built with Rich.

## Features

- Check one or multiple usernames
- Generate random usernames
- Generate pronounceable usernames
- Choose the minimum and maximum username length
- Allow lowercase letters
- Allow uppercase letters
- Allow numbers
- Allow underscores
- Generate a specific amount of usernames or run forever until you press **Ctrl + C**
- Score every username from 0–100
- Generate a strong password for every available username
- Automatically save available usernames
- Recheck saved usernames to remove any that have been taken
- Save your favourite generator settings as presets
- View lifetime and daily statistics
- Open the Roblox signup page with a saved username already filled in

## Installation

Install the required packages:

```bash
pip install requests rich
```

If you want to use the account creation feature, also install:

```bash
pip install selenium undetected-chromedriver setuptools certifi
```

## Running

```bash
python roblox_username_checker.py
```

## Files

The script creates a few files automatically:

- `available_usernames.txt` – saves every available username with its generated password.
- `presets.json` – stores your saved generator presets.
- `stats.json` – stores your lifetime statistics.
- `signup_cooldown.json` – keeps track of the signup cooldown.

## Username Generator

You can customise how usernames are generated by choosing things like:

- Minimum and maximum length
- Lowercase letters
- Uppercase letters
- Numbers
- Underscores
- Pronounceable names

You can also enter **0** when asked how many usernames to generate to keep it running until you stop it with **Ctrl + C**.

## Username Scores

Every available and taken username gets a score out of 100. Generally, shorter and cleaner usernames receive higher scores.

## Recheck

If you've already built up a list of available usernames, you can use the Recheck option to go through them again. Any usernames that have since been taken or blocked are automatically removed from your saved list.

## Statistics

The script keeps track of things like:

- Total usernames generated
- Total usernames checked
- Available usernames found
- Taken usernames
- Errors
- Best username found
- Daily activity
- Overall availability rate

## Notes

This tool uses Roblox's public username validation endpoint. Please don't spam the API or abuse it.

The account creation option only fills in the signup form for you. You still need to complete the CAPTCHA yourself.
